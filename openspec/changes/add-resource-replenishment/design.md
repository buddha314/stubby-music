# Design
Use 2700 seconds of daylight followed by 900 seconds of night. Start at daylight. Count night boundaries, scheduling next-night returns strictly after the collection night. Resource policies default to never; elapsed-time returns use game milliseconds. Retain dormant bug entities and their independent synthesis graphs to avoid graph recreation races; mask visuals and mute gains while depleted. Return does not grant inventory or play collection confirmation. Bracket keys select 0.25, 0.5, 1, 2, 4, 8, 16 or 64 times simulation speed; backslash restores 1. Audio pitch, flash duration and musical clocks remain sample timed. Sunlight, ambient brightness, sky intensity and fog color follow the sun elevation continuously. Authored progression/mood key interpolation remains with the atmosphere change.

Sun geometry uses an equinox declination of zero and latitude 37°N. Compress the below-horizon half of the astronomical arc into the 15-minute night while retaining the 45-minute daylight. East is +X, north is -Z. A separate emissive sun disc follows the same direction as the sunlight, avoiding a second baked stationary sun in the HDRI.

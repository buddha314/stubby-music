# Resource replenishment and simulation time

## Why
Finite pickups should return after a configured interval; lightning bugs return the next night. Players need control over simulation speed.

## What Changes
Add catalog replenishment policies, a deterministic shared day/night calendar using Satisfactory timing, simulation speed controls, and a moving early-spring sun at 37°N. Preserve finite yields and independent audio timing. Infinite mine production remains separate.

## Impact
Resource catalog, harvest ledger, game resource lifecycle and timing. Dormant bugs retain their seeded clocks but emit no audible or visible effects.

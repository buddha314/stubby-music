## Why
Floating bugs need ground cues so players can judge distance and a clear collection prompt in reach.

## What Changes
- Hover 1–3 metres above the terrain.
- Soft ground shadows pulse with each sample-clock flash.
- Centered E collection prompt within the existing 3m collection range.

## Capabilities
### Modified Capabilities
- `lightning-bug`: grounded hover positions and pulsing shadows.
### New Capabilities
- `collection-prompt`: contextual collection HUD.

## Impact
Game presentation and HUD only; existing harvest rules remain.

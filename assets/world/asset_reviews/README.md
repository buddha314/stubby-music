# Asset review scenes

Small Jackdaw scenes for looking at new assets in the game's own light, before they have
a place in a level. Each places a set of prefabs near the opening view; they are not levels
and the game never loads them on its own.

| Scene | What it shows |
| --- | --- |
| [dancers.bsn](dancers.bsn) | The Dancers: four body shapes by four skin tones, keeping time with a burbler; two rows dance |
| [vardo.bsn](vardo.bsn) | The vardo, the player's base, with the cyber-cob standing between its shafts (its `Idle` clip loops), beside a campfire |
| [city.bsn](city.bsn) | The City kit's reference district (`docs/art/city-kit/`): canal, blocks, the mixed-use neighbourhood, gallery, concert hall, rail, monument and Dancers, lifted 2.3 m because the ground has no canal cut; generated by `tools/blender/create_city_district.py` |
| [city_mixed_bay.bsn](city_mixed_bay.bsn) | The City's mixed-use validation bay: a shop and the residents' door, an office floor, three storeys of homes (one furnished), the glass stair tower and a roof garden, ahead of the spawn; generated by `tools/blender/create_city_mixed_bay.py` |
| [homestead.bsn](homestead.bsn) | The Dancer cottage with its homestead props (table, stools, bench, barrels, bucket, planters, hammock) and a campfire for scale |

Build `stubby_jackdaw` first, then from the repository root:

```sh
python3 tools/jackdaw_timed_test.py --asset-review homestead --name homestead
```

The watchdog runs the standalone game for 20 seconds with the seeded layout off and saves
a screenshot to `/tmp/stubby-asset-homestead.png`. To walk around instead, run the game
directly: `target/debug/stubby_jackdaw --seed=42 --no-seeded-layout
--scene=world/asset_reviews/homestead.bsn`, or open the scene in Jackdaw and press Play.

# stubby-music

Early sketches of a game using modular synthesis to do a factory style simulation game. I dunno, it's too big.

This repository now includes an initial project scaffold for both:

- a Bevy-based Rust game project
- a Jackdaw editor project manifest for opening the project in the editor

## Run the game

```bash
cargo run
```

## Jackdaw editor

The project metadata lives in `.jackdaw/project.json`, which configures the editor to run the Rust project with `cargo run`.
